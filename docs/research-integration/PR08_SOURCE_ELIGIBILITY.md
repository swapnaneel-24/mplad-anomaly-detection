## 1. Candidate evaluation

Five result categories were evaluated per the contract §3:

### A. Aggregate scientific results

**Candidate:** `PHASE6_REFERENCE_VALUES` in `src/mplad/stream_a/phase6.py`

18 precomputed aggregate reference values from the canonical ULB
credit-card fraud benchmark experiment:
- sample_size (30,000), fraud_label_count (47)
- IF_003/LOF_004 flagged counts (300 each)
- Cross-method overlap: intersection 107, union 493
- Agreement groups: Both=107, IF-only=193, LOF-only=193, Neither=29,507
- Per-group fraud counts: Both=30, IF-only=0, LOF-only=8, Neither=9
- Spearman correlation IF_003–LOF_004 = 0.3666
- Jaccard IF_003–LOF_004 = 0.2170
- Hypergeometric enrichment = 35.67×, log10 upper tail = -140.30

**Eligibility:** **ELIGIBLE.** The values are:
- Machine-readable (Python dict, parseable via AST).
- Aggregate-level (no record-level mapping required).
- Well-documented (dataset, model, evaluation context, limitations all
  documented in the phase contracts and interpretation principles).
- Frozen (SHA-256 verified by `ci/frozen_research_manifest.json`).
- Sourced from a verified experiment (ULB benchmark, 30k sample, 47
  fraud labels, bottom-1% threshold, IF_003 vs LOF_004).

**Eligibility:** **INELIGIBLE** for direct integration (used as

**Finding:** The source code files (`phase3.py`, `phase4.py`,
`phase5_analysis.py`, `phase6.py`) contain the research pipeline code
but NOT precomputed model outputs. The code, when executed with the ULB

**Eligibility:** **INELIGIBLE** for execution; the frozen constants
exported by `phase6.py` (`PHASE6_REFERENCE_VALUES`,
`INTERPRETATION_PRINCIPLES`) are ELIGIBLE for read-only serving.

## 2. Selected source family

**Selected:** `phase6-reference-values` — the 18 precomputed aggregate
reference values from `PHASE6_REFERENCE_VALUES` in
`src/mplad/stream_a/phase6.py`, supplemented by:

- `INTERPRETATION_PRINCIPLES` (7 authored strings from the same file)
- `EXPLORATORY_SELECTION_CAVEAT` (1 string from `phase5_analysis.py`)
- Experiment configuration from `config.py` (IF/LOF parameter grids,
  threshold rule, canonical run IDs)

**Scientific justification:**
- The values are the final cross-method consistency reference values
  from the canonical experiment.
- They are aggregate-level — no per-record mapping is required,
  eliminating the row-to-record correspondence risk.
- The experimental context is fully documented: ULB benchmark, 30k
  sample, 47 fraud labels, bottom-1% threshold, IF_003 (100 estimators,
  5% max_samples, seed 42) vs LOF_004 (50 neighbors, euclidean).
- The scientific limitations are explicitly authored (7 interpretation
  principles + exploratory caveat).
- The provenance is deterministic: the source artifact's SHA-256 is
  verified by the frozen integrity checker.
